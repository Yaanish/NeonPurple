# Purple Neon - Notepad++ Theme

A dark, cyberpunk-inspired theme for Notepad++ featuring deep purple backgrounds with vibrant neon purple and magenta accents. Perfect for late-night coding sessions and developers who love a futuristic aesthetic.

##  Features

- **Eye-friendly dark purple background** - Reduces eye strain during extended coding sessions
- **High-contrast neon accents** - Syntax elements pop with vibrant purple and magenta colors
- **Comprehensive language support** - Styled for C/C++, Python, JavaScript, HTML, XML, JSON, and more
- **Consistent color scheme** - Unified look across all supported languages
- **Customized UI elements** - Matching line numbers, margins, selection highlights, and more

##  Installation

### Method 1: Direct Import (Recommended)

1. Download the `PurpleNeon.xml` file from this repository
2. Open Notepad++
3. Navigate to **Settings** → **Style Configurator**
4. Click the **Import** button at the bottom
5. Select the downloaded `PurpleNeon.xml` file
6. Click **Open**
7. The theme will be applied immediately

### Method 2: Manual Installation

1. Download `PurpleNeon.xml`
2. Copy the file to your Notepad++ themes folder:
   - Windows: `%APPDATA%\Notepad++\themes\`
   - Or: `C:\Program Files\Notepad++\themes\` (if installed system-wide)
3. Restart Notepad++
4. Go to **Settings** → **Style Configurator**
5. Select "Purple Neon" from the theme dropdown

##  Customization

Want to tweak the colors? You can edit the `PurpleNeon.xml` file:

1. Open the XML file in any text editor
2. Find the color codes (format: `fgColor="RRGGBB"` for text, `bgColor="RRGGBB"` for background)
3. Replace with your preferred hex colors
4. Save and re-import into Notepad++
