\# Purple Neon - Notepad++ Theme



Dark purple theme with vibrant neon accents for Notepad++.



\## Preview



!\[Theme Preview](screenshots/preview.png)



\## Installation



1\. Download `PurpleNeon.xml`

2\. Open Notepad++

3\. Go to \*\*Settings\*\* → \*\*Style Configurator\*\*

4\. Click \*\*Import\*\* and select the downloaded XML file

5\. Restart Notepad++ (if necessary)



\## Color Palette



\- Background: `#1A0033`

\- Foreground: `#E0B0FF`

\- Keywords: `#FF00FF`

\- Strings: `#C77DFF`

\- Comments: `#9D4EDD`

\- Numbers: `#BF40BF`
